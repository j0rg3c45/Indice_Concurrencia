# Glosario — Índice de Concurrencia

| Término | Definición |
|---------|-----------|
| POI | Point of Interest (Punto de Interés). Ubicación georreferenciada de un negocio, servicio o equipamiento |
| Overture Maps | Fundación de datos abiertos geoespaciales respaldada por Meta, Microsoft, Amazon y TomTom |
| Índice de Concurrencia | Métrica compuesta que cuantifica la densidad, diversidad y vitalidad de la actividad económica en un territorio |
| Macrocategoría | Agrupación temática de las categorías originales de Overture Maps en 13 grupos funcionales |
| Buffer | Zona de influencia (100m) alrededor del eje vial de Av. Roosevelt |
| Bounding box | Rectángulo envolvente mínimo que contiene el área de estudio |
| Línea base | Medición inicial pre-intervención que sirve como punto de comparación |
| Post-intervención | Medición posterior a las obras públicas para evaluar impacto |
| Confianza | Score de Overture Maps (0-1) que indica la certeza de que el lugar existe y está activo |
| Release | Versión mensual de los datos publicados por Overture Maps Foundation |
| Spatial filter | Operación GIS que selecciona solo los puntos dentro de un polígono dado |
| CRS | Sistema de Referencia de Coordenadas (EPSG:4326 = WGS84 geográfico) |
| Datalake | Repositorio centralizado de datos del equipo de Gobierno de Datos |
| ITT | Índice de Transformación Territorial (proyecto hermano que mide transformación integral) |
| Territorio espejo | Corredor vial comparable usado como referencia para contextualizar los valores de Roosevelt |
| Presencia digital | Existencia de un lugar en plataformas digitales (Google, Meta, etc.) aunque no tenga registro formal |
| GeoJSON | Formato estándar abierto para representar datos geoespaciales |
| CLI | Command Line Interface; herramienta de línea de comandos de Overture Maps |
| Donut chart | Gráfico circular con hueco central, usado para mostrar proporciones |
| Barras agrupadas | Gráfico de barras que compara múltiples zonas lado a lado por categoría |
